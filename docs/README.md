## Project Overview

PathWise accepts multiple documents (PDFs, images, text) and:

1. **Extracts** structured information using Sarvam AI's document intelligence
2. **Validates** extracted evidence against source documents
3. **Analyzes** cross-document relationships and dependencies
4. **Prioritizes** actions based on deadlines, blockers, and urgency
5. **Translates** final plans into 22+ Indian languages

Built for the Sarvam AI Hackathon 2026.
